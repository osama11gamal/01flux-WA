# Community Integrations

Third-party integrations and adapters built by the community on top of 01flux WA's REST API.

> **Looking for Chatwoot, Typebot, and other first-party integrations?** Those ship as official
> sandboxed plugins on the Integration Fabric — see the [01flux WA-plugins](https://github.com/rmyndharis/01flux-wa-plugins)
> catalog. This page lists only community-built projects.

> ⚠️ **These projects are community-maintained and are not affiliated with or endorsed by 01flux WA.**
> They may lag behind 01flux WA API changes. Verify compatibility and review the source before using
> them in production.

| Integration         | Platform                                                      | Source                                                                                                                                         | Notes                                                                                                                                  |
| ------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **ioBroker.01flux-wa** | [ioBroker](https://www.iobroker.net/) (home / IoT automation) | [ThorstenBoettler/ioBroker.01flux-wa](https://github.com/ThorstenBoettler/ioBroker.01flux-wa) · [npm](https://www.npmjs.com/package/iobroker.01flux-wa) | Send text / image / video / audio / document messages to chats and groups through 01flux WA's REST API, with Blockly blocks. Early stage. |

Maintain an integration built on 01flux WA and want it listed here? Open a PR adding a row (or an issue), including the repository link and a one-line description.

For the first-party n8n nodes, see [n8n Integration](./22-n8n-integration.md).
